# 하루언어

한국어·일본어·영어를 한 문장 안에서 연결해 배우는 무료 웹 학습 앱입니다.

## 현재 웹판
- 6가지 언어 방향 학습
- 아침·점심·저녁 집중 세션
- 회화·단어·문법·독해 통합 수업
- 모델 음성 및 느린 음성
- 녹음·재생·음성 인식
- 문장 정확도·말하기 속도·침묵·피치 변화 기초 분석
- 오답노트·XP·학습 기록
- 학습 XP 연동 Haru P 포인트 원장과 일일 적립 한도
- 오늘 3회 학습 완료 보너스
- 보상형 광고·친구 추천·상품권 교환을 위한 안전형 연동 자리
- 오프라인 캐시 및 홈 화면 설치

## 리워드 V1 안전 원칙
현재 Haru P는 브라우저 학습 상태를 기준으로 동작하는 학습용 포인트입니다. 보상형 광고는 광고 제공사의 시청 완료 검증, 친구 추천은 계정/서버 기반의 실제 학습일 검증, 상품권 교환은 서버 측 변경 불가능한 포인트 원장과 중복·부정 사용 검증이 갖춰진 뒤 활성화합니다. 브라우저 `localStorage` 값만으로 현금성 보상을 지급하지 않습니다.

발음 결과는 웹 브라우저 기반의 기초 코칭이며, 실제 음소/피치 악센트 정밀 평가는 최종 Android 앱 단계에서 강화합니다.
