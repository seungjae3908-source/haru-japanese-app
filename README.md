# 하루언어

한국어·일본어·영어를 서로 교차 학습하고, 음성 녹음과 브라우저 음성 인식을 이용해 발음을 반복 교정하는 무료 웹앱입니다.

## 현재 웹판 기능

- 한국어↔일본어, 한국어↔영어, 일본어↔영어 6개 학습 방향
- 세 언어 문장·일본어 읽기·직역·단어·문법
- 아침 학습, 점심 회상, 저녁 말하기 흐름
- 목표 언어 TTS 보통·느린 음성
- 마이크 녹음과 내 음성 재생
- 음성 인식 문장 정확도 및 빠진·추가 구간 표시
- 녹음 길이, 침묵 비율, 유창성, 억양 변화 1차 분석
- 오답노트, 개인 단어장, XP와 학습 통계
- 오프라인 캐시와 홈 화면 설치

## 발음 점수 안내

웹판의 문장 정확도는 브라우저가 인식한 결과와 목표 문장을 비교한 값입니다. 속도·유창성·억양 변화는 녹음 길이, 침묵 비율과 음높이 변화를 분석합니다. 원어민 음소와 피치 악센트를 직접 정밀 대조하는 기능은 최종 Android APK에서 별도 음성 분석 엔진으로 확장할 예정입니다.
